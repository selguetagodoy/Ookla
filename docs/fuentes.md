# Fuentes

## Ookla Open Data

Repositorio oficial de datos abiertos de Speedtest by Ookla.

- GitHub oficial: `teamookla/ookla-open-data`
- Cobertura de tiles desde Q1 2019.
- Formatos publicados: Shapefile y Apache Parquet.
- Variables principales: velocidad de descarga, velocidad de subida, latencia, número de tests, dispositivos y quadkey.
- La documentación oficial consultada en agosto de 2026 identifica Q1 2026 como el trimestre completado más reciente disponible en el repositorio.

## Speedtest Global Index

Se utilizaron observaciones oficiales disponibles en páginas país de Speedtest Global Index para complementar el análisis cuando correspondía. Estas observaciones no se mezclan automáticamente con los agregados construidos desde tiles de Ookla Open Data.

## Akamai State of the Internet

Los antecedentes históricos corresponden a informes oficiales de Akamai *State of the Internet — Connectivity*. Se utilizan para el periodo previo a Ookla Open Data y se conservan como una familia metodológica separada.

## Criterio de inclusión

La base principal privilegia fuentes oficiales o archivos oficiales recuperables. Fuentes secundarias pueden servir como referencia o contraste, pero no se utilizan para completar automáticamente valores ausentes en la serie principal.

## Nota sobre propiedad de los datos

Los datos originales, nombres comerciales y marcas pertenecen a sus respectivos titulares. Este repositorio contiene una selección y organización independiente para fines de análisis y reproducibilidad. Se deben revisar los términos de uso y licencias de cada fuente antes de redistribuir datasets originales completos.
